# Data description

This academic project uses **fictional example data** for a cinema chain named *Cinema & Chill*.

The presentation illustrates data relating to:

- Cinema locations and cinema types (multiplex, open-air cinema, and movie theatre).
- Cities and administrators.
- Movies associated with cinema venues.
- Cardholders and their associations with cinemas.

Sample tables were imported from **Excel into MySQL** during the project. The original Excel workbooks and SQL export files are **not included** in this repository. The example records, normalisation discussion, and database structure are documented in [the project presentation](../presentation.pdf).
